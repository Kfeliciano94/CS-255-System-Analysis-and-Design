# CS 255 – System Analysis and Design

## DriverPass Project

The DriverPass project involved designing a system for a company that wanted to help students prepare for their driving tests. The client wanted an online system where students could take practice tests, schedule driving lessons, and track their progress. The system also needed to allow staff to manage appointments and student information.

## Reflection

### What did you do particularly well?

I think I did well at understanding the client's requirements and organizing them into a system design. I was able to identify the important features and create diagrams that showed how the system would work.

### If you could revise one part of your work, what would you improve?

If I could change one thing, I would improve my UML diagrams by adding more details to make the different processes easier to understand. I would also make sure the diagrams clearly show how users interact with the system.

### How did you interpret the user's needs and implement them into your system design?

I reviewed the DriverPass interview and focused on what the client wanted the system to do. I used those requirements to plan features like online practice tests, lesson scheduling, and account management. Understanding the user's needs is important because the system should be easy to use and meet the client's expectations.

### How do you approach designing software? What strategies would you use in the future?

When designing software, I think it is important to understand the requirements before starting the design. I would begin by identifying what users need, organizing the main features, and creating diagrams to show how everything connects. In the future, I would continue using UML diagrams and user feedback to improve my designs.
